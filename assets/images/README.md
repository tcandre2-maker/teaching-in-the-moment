## Integration requirements

- Each image is used once and only beside the matching instructional context.
- Use descriptive alt text that reports visible actions without inferring unobservable intent.
- Preserve equivalent scenario text so no decision depends on seeing the image.
- Do not use Image 6 (transit kiosk).
- The image is contextual support, not a substitute for the learner's written treatment plan or observable data.
